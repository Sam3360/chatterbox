# chatterbox

simple terminal style chat app made with html and firebase. live messages save automatically to firebase so chat history stays when you refresh.

## features

* simple 2000s terminal / irc look
* works on mobile and pc
* multi user chatting in real time
* saves messages using firebase realtime database

## how to run it

1. clone the repo or download the `index.html` file
2. open `index.html` in any browser
3. enter a handle and start chatting

## setup firebase

if you want to use your own database:

1. go to firebase console and make a new project
2. create a realtime database in test mode
3. copy your firebase config keys
4. paste them into the script tag in `index.html`
